프롬프트 배틀
프롬프트 교육을 조금더 접근성있게 재밌게 해보자!
말을 조리있게, 나의 근거를 보다 명확하게!
어린 학생들도, 공부가 재미없는 20대 대학생들도  재밌게 프롬프팅 할 수 있도록 게임화 요소 첨가~

기능요소
튜토리얼 기능
상대방 없이 혼자서 게임을 진행하는 식으로 튜토리얼 진행
하이라이트 박스로 클릭할 부분들 명시화 (Ex. 게임 시작, 프롬프트 박스, 등)
게임 시스템
I.게임 시작 버튼 (버튼 누르면 매칭)
게임 시작 버튼을 누르면 임의 매칭과 코드 매칭 선택 가능
임이 매칭을 선택할 경우 모르는 사람과 매칭 본인 랭크에 맞도록 매치되는 것처럼 보이기
 (but 시간상 입장 코드로 입장하는 것을 구현)
코드 매칭을 선택할 경우 방 만들기 or 코드 입력하기 선택 가능
방만들기를 선택할 경우 방이 만들어지면 방 코드 제공
코드 입력하기를 선택할 경우 만들어진 방에 입장 가능
II.나가기 버튼 (버튼 누르면 중도 포기)
게임이 진행되는 도중에 도저히 답이 없다 생각되면 나갈 수 있음
나가기를 누를 경우 “정말 게임을 포기하실건가요?” 출력과 함께 예 / 아니오 선택 가능
예를 누를 경우 게임이 종료 되며 나가짐 + 상대방도 게임 종료
아니오를 누를 경우 게임이 계속 진행
III.방 생성
방 제목 입력 후 설정 시작
I에서 방 만들기를 선택할 경우 난이도, map선택 및 제한시간, 프롬프트 제한 설정 가능
난이도: 주제문의 난이도 설정
map선택: 동양풍, 미래풍, 중세, 우주 선택 가능 (동양풍만 구현할거지롱 ㅋㅋ)
제한시간: 게임의 총 진행시간을 설정 가능 (2분/3분/5분)
프롬프트 제한: 50자 / 100자 / 150자 / 300자 / 무제한
설정 완료 후 방 생성 누르면 코드 제공 (복붙기능도 제공)
IV.캐릭터 커스터마이징
내 옷장 클릭
다양한 캐릭터 선택 가능 (고양이/비둘기/강아지/씹덕)
내 옷장에서 캐릭터 선택할 경우 “선택 완료!”라 출력되며 선택했음을 알리는 메세지 제공
이후 내 옷장을 나가면 해당 캐릭터로 게임 플레이 가능
V. 게임 시스템
프롬프트 입력창: 나의 프롬프트를 입력하는 창
주제문 룰렛: 주제문 / 분량 / 필수 키워드  총 3가지 내용이 뜨게 됨
설명창: 프롬프트를 바탕으로 AI가 대답하는 창
→ 설명 창에 AI가 글이 나오는게 차근차근 보임 (Ex. chatGPT 대답처럼 [뭔가 한자씩 따다다다다닥 나오는 느낌]
→ 끝까지 나올 경우 평가 AI가 설명창을 읽기 시작 (제대로 설명이 되었는지) [이때 AI가 읽는 모습을 하이라이트로 시각화]
→ 유저에게 자기 프롬프트가 만드는 결과를 읽을 수 있도록 하기 위한 기능 
	(너무 빨리 채점되고 PASS / RETRY가 뜨면 사용자가 학습하는게 없음
→ 평가 기준에 따라 적합하다면 검은 화면 뜨면서 PASS
→ 부적하다면 블루스크린 뜨면서 RETRY
내 캐릭터: 내 옷장에서 선택한 캐릭터가 옆에 떠있음 (이때 캐릭터를 클릭할 경우 캐릭터가 반응하며 채팅 기능 사용 가능)
→ 채팅을 입력하면 캐릭터가 말하는듯이 말풍성이 뜨며 내가 한 말이 적힘
→ 옆에서 반응형으로 움직이는 캐릭터 (PASS하면 야호! / RETRY면 엉엉 울기)
제한 시간 창 (창이라기 보단 뭔가 체력바? 느낌으로 시간이 점점 줄어가는걸 표현하면 될듯)
→ 이때 10초 남으면 10 9 8…카운트다운 해줌
VI. 게임 종료
제한 시간이 다 줄어들면 게임이 반투명 흑백으로 바뀌면서 두둥! 하고 게임 결과 뜸
게임 결과는 The Winner is…….. Player A!!! 이런식으로 뜸 들이고 승리자 닉네임 팝업시키는 방식으로 진행
클릭하면 빠르게 넘어가지며 내 게임 결과 확인 가능
→ 총 게임 시간 / 내가 얻은 포인트(맞춘 주제 수) / Win Lose 승리 여부
	 (이때 승리하면 막 옆에서 캐릭터들 환호하면서 축포 터짐 / 패배하면 캐릭터들 울면서 바닥 치고 난리남)
게임 종료 이후 나가기 / 한번 더 하기 버튼 존재 
한번 더 하기 클릭할 경우 같은 방 설정으로 게임을 한번 더 할 수 있음
나가기 누를 경우 그냥 로비로 돌아와짐
VII.





게임 진행
게임 시작과 동시에 3 2 1 카운트 다운이 나타나며 주제문이 선정됩니다
(Ex. 광합성 / 3줄 이내로 / 미토콘드리아) 대표 주제문 / 분량 / 필수 키워드
유저는 AI가 주제문에 맞는 답변을 받을 수 있도록 프롬프팅을 진행 (이때 해당 주제, 분량, 키워드들을 직접 언급할 순 없음)
ㄴ 프롬프트 글자 제한별로 게임 분리(50자 게임, 100자 게임, 150자 게임, 무제한 게임)
ㄴ 시간 제한 있음

프롬프팅 예시)

유저A: 나는 어린 아이들을 가르치는 교사고 현재 학생들에게 식물이 에너지를 만드는 과정 대해 설명을 해야해. 내용을 간결하고 짧게 설명해줘.

유저B: 식물이 힘내는법 알려줘. 짧게

AI가 이 프롬프트를 바탕으로 각각 설명문을 출력
이때, 정답, 즉 주제문에 해당되는 내용이 녹아있으며 분량역시 적합한 설명문이 출력되는 쪽은 PASS  (다음 주제문으로 넘어감)
이걸 반복해서 제한시간 내에 더 많은 주제문을 PASS한 쪽이 승리! [끄투 온라인, 테트리스 느낌으로]
