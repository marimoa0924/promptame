# 11. AI 선택과 솔로 플레이

요청에 따라 원래 스펙(AI는 Gemini Flash 계열)을 넓혀서, 방을 만들 때 Gemini, GPT, Claude 중에서 AI를 고를 수 있게 했고, 상대 없이 혼자 하는 솔로 플레이를 추가했다. [확정]

## 1. AI 제공자 선택

| 항목 | 내용 | 라벨 |
|---|---|---|
| 선택 위치 | 방 만들기와 솔로의 "AI 모델" 버튼(Gemini, GPT, Claude). 방 설정이라서 방의 두 사람이 같은 AI를 쓴다 | 확정 |
| 고를 수 있는 것 | 서버에 API 키가 있는 제공자만. 키가 없는 것은 비활성으로 보이고, 마우스를 올리면 이유가 나온다 | 확정 |
| 키가 하나도 없을 때 | 버튼 대신 "목 AI (서버에 API 키가 없어요)"가 보이고 목 AI로 진행한다 | 확정 |
| 기본 AI | 키가 있는 것 중 Gemini, GPT, Claude 순. `DEFAULT_AI`로 바꿀 수 있다 | 제안 |
| 연습봇, 튜토리얼 | 항상 목 AI를 쓴다(비용이 들지 않게) | 확정 |
| 화면 표시 | 내 보드 이름표에 `나 · Gemini`, `나 · GPT`, `나 · Claude`, `나 · 목 AI` | 확정 |

### 1.1 호출 방식(세 제공자 공통) [확정]
- 유저 프롬프트를 시스템 프롬프트 없이 `user` 메시지 하나로 그대로 보낸다.
- 최대 출력 1024토큰, 응답 한도 8초, 오류나 빈 응답은 같은 프롬프트로 최대 2번 더 시도한다(06 문서). 결과가 끝내 없으면 그 전송은 시도로 세지 않는다.
- 답변이 토큰 한도로 잘리면 분량 초과로 판정한다. 잘림을 알아내는 값은 제공자마다 다르다: Gemini `MAX_TOKENS`, GPT `finish_reason: length`, Claude `stop_reason: max_tokens`.
- 안전 필터나 거절은 비어 있는 응답과 같이 재시도한다. GPT `content_filter`나 `refusal`, Claude `refusal`.
- 판정은 AI와 무관하게 코드(`promptRules.js`)가 한다. 어떤 AI를 써도 규칙은 같다.

### 1.2 설정(환경변수) [제안]
| 제공자 | 키 | 모델(기본값) |
|---|---|---|
| Gemini | `GEMINI_API_KEY` | `GEMINI_MODEL` (`gemini-3.5-flash-lite`) |
| GPT | `OPENAI_API_KEY` | `OPENAI_MODEL` (`gpt-4o-mini`) |
| Claude | `ANTHROPIC_API_KEY` | `ANTHROPIC_MODEL` (`claude-haiku-4-5-20251001`) |

- 서버를 켤 때 키가 있는 제공자마다 한 번 호출해서 연결을 확인한다. 모델 이름이 틀렸으면(404, 400) 그 키로 쓸 수 있는 모델 목록을 보여 준다.
- 키는 서버에만 있고, 브라우저로 가는 `/config.json`에는 제공자 이름, 사용 가능 여부, 모델 이름만 있다.

### 1.3 한계
- GPT와 Claude는 실제 호출을 시험하지 못했다(키가 없었다). 요청과 응답 처리는 가짜 응답으로 시험했다. 키를 넣은 뒤 서버를 켤 때 나오는 연결 확인 줄로 확인한다. [확정]
- GPT 기본 모델 `gpt-4o-mini`가 지금도 쓸 수 있는지는 확인하지 못했다. 안 되면 연결 확인 줄에서 쓸 수 있는 모델 목록이 나온다. [미정]
- 추론 모델(생각 토큰을 쓰는 GPT 계열)은 생각에 쓴 토큰도 출력 한도에 들어가서, 한도 1024가 모자라면 답이 비거나 잘릴 수 있다. 이 게임은 싸고 단순한 모델을 쓰는 것을 전제로 한다. [제안]
- 제공자마다 같은 프롬프트에 다르게 답한다. 같은 방에서는 같은 AI라 공정하지만, 다른 AI를 쓴 판끼리의 PASS 수는 비교가 어렵다. 랭킹과 솔로 랭킹은 AI를 구분하지 않는다. [제안]
- 호출 비용은 서버 운영자의 키로 나간다. 사용자가 늘면 비용도 는다. [확정]

## 2. 솔로 플레이

상대 없이 혼자, 시간 안에 최대한 많은 문제를 PASS하는 점수 도전이다. [확정]

| 항목 | 내용 | 라벨 |
|---|---|---|
| 진입 | 로비의 "솔로" 탭에서 맵, 난이도(4단계), 제한시간(2/3/5분), 프롬프트 글자 제한, AI를 고르고 시작 | 확정 |
| 진행 | 혼자라서 바로 카운트다운이 시작된다. 점수는 PASS한 문제 수다. 연속 PASS 페널티는 걸 상대가 없어 효과가 없고, 건너뛰기는 쓸 수 있다(내 입력 3초 정지) | 확정 |
| 끝 | 시간이 끝나면 이기고 지는 것 없이 "솔로 완료!" 또는 새 기록이면 "신기록!"이 뜬다. 연습봇은 부를 수 없다 | 확정 |
| 중간에 나가기 | 기록이 남지 않고 방이 닫힌다 | 확정 |
| 한 번 더 | 혼자라서 바로 새 판이 시작된다. 이미 나온 문제는 피한다 | 확정 |

### 2.1 기록 [제안]
- **개인 최고 기록**: 난이도와 제한시간 조합마다 맞힌 문제 수의 최고. "내 기록"의 솔로 기록에 보인다.
- **솔로 랭킹**: 난이도와 제한시간별로 계정마다 최고 기록 상위 20명(화면에는 10명). 랭킹 창의 "솔로" 탭에서 난이도와 시간을 골라 본다. 대전 랭킹(RP)과는 따로다.
- **재화**: 맞힌 문제 하나당 +1, 한 판에 최대 +10, 솔로로 재화를 받는 판은 하루 5판까지. 맞힌 것이 없으면 없다.
- **성적**: 맞힌 문제, 한 번에 맞힌 수, 최고 연속 PASS는 성적에 더하지만 대전 판 수와 승패에는 안 들어간다.
- **프롬프트 습관 분석**: 솔로에서 쓴 프롬프트도 습관 분석 기록에 들어간다(10 문서).
- 튜토리얼처럼 서버에 방이 만들어진다. 같은 코드로 들어올 사람은 없다. [확정]
