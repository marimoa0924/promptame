## 3. 충돌과 수정 기록

| ID | 충돌 | 처리 |
|---|---|---|
| X-01 | 이전에 제안한 "AI 재시도 대기 시간을 타이머에서 뺀다"와 확정된 "빼지 않는다, 판은 동시에 끝난다"가 충돌한다 | 확정을 따른다. 시간은 안 빼고 재시도는 시도로 세지 않는 것만 남긴다 |
| X-02 | 이전 수치표의 "AI 오류가 계속되면 이번 문제는 무효"는 레이스에서 상대에게 불리하다 | 문제가 아니라 그 전송만 무효(`attempt:void`)로 바꿨다 |
| X-03 | 이전 제안 "답변 재생은 초당 40자 고정"은 300자일 때 7.5초 걸려 두 사람이 오래 잠긴다 | 최소 초당 40자, 재생 시간 최대 2.5초로 바꿨다 |
| X-04 | 기획서의 "나가기를 누르면 상대방도 게임 종료"와 확정된 "상대 쪽 처리는 미정" | 상대는 즉시 승리 처리로 정했다 |
| X-05 | 기획서의 "임의 매칭처럼 보이는 연출"과 확정된 "버튼만 만들고 구현 안 함" | 확정을 따른다. 안내만 띄운다 |
| X-06 | 기획서의 "한번 더 하기 클릭 시 같은 방 설정으로 다시"는 동의 여부가 없다 | 상대 동의가 필요하다 |
| X-07 | 기획서의 "포인트(맞춘 주제 수)", "점수", "재화", "랭크"가 섞여 있다 | 판 안의 값은 점수, 이후 단계의 재화는 코인, 랭크는 랭크 점수로 통일했다 |
| X-08 | 기획서의 "같은 주제문을 받는다"와 "PASS하면 다음으로 넘어간다"가 진행 방식을 정하지 않는다 | 같은 문제를 동시에 푸는 레이스로 확정했다 |
| X-09 | 기획서의 프롬프트 제한 문구에 300자가 빠져 있다 | 확정 사항(50, 100, 150, 300, 무제한)을 따른다 |
| X-10 | 기획서의 "총 게임 시간" 표시는 시간이 고정이라 의미가 없다 | 포기, 부전패일 때의 실제 경과 시간을 의미한다 |
| X-11 | 파일 경로가 `src/shared/`, `data/`, `tools/`로 되어 있으나 저장소는 모두 루트에 있다. 레퍼런스 이미지도 png가 아니라 webp다 | 목표 구조를 정하고 이동은 A-1에서 한다 |
| X-12 | 옛 `from openpyxl import Workbook.py`는 현재 xlsx와 내용이 달라 원본으로 쓸 수 없다 | 삭제 대상으로 표시했다 |
