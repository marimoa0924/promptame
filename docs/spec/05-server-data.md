# 05. 서버 데이터

## 1. 저장 방식

| 단계 | 방식 | 라벨 |
|---|---|---|
| 방과 진행 중 판 | 서버 메모리만 쓴다. 서버를 다시 켜면 사라진다 | 제안 |
| 계정, 랭킹, 재화, 성적, 프롬프트 기록, 본 문제 기록 | `store.json`(`DATA_FILE`)에 남긴다 | 제안 |
| 문제 데이터 | `data/problems.json`을 서버가 시작할 때 읽는다 | 확정 |
| P2 | 재화, 랭크, 가챠가 들어오면 SQLite 같은 DB가 필요하다. 어떤 DB인지는 그때 정한다 | 미정 |

## 2. 메모리에 두는 데이터 (P0, P1) [제안]

```js
Player  { playerId, nickname, characterId, resumeToken, socket|null, roomCode|null, lastSeenAt }
Room    { code, title, settings, hostId, status, playerIds[2], ready{}, createdAt,
          game: Game|null, rematch: {requestedBy, expiresAt}|null }
Game    { id, startedAt, endsAt, sequence[40], seq, phase, scores{}, streaks{},
          skipVotes{}, lockedUntil{}, attempts[], usedProblemIds[], inflight{} }
Attempt { id, seq, playerId, no, promptText, answerText, verdict, status, sentAt, doneAt, usage }
```

- `sequence`는 판 시작 때 만든 문제 목록(`{problem, lengthRule}` 40개)이다. 클라이언트에는 현재 문제 하나만 보낸다. [확정]
- `attempts`는 결과 화면의 문제별 프롬프트와 AI 답변 공개와 디버깅에 쓴다. 방이 닫히면 같이 버린다. [제안]
- 한 번 더 하기를 하면 새 `Game`을 만들고 `usedProblemIds`를 이어받는다. [확정]
- 프롬프트와 답변 본문은 로그에 남기지 않는다(개인정보와 비용 이유). 길이와 판정 코드만 남긴다. [제안]

## 3. 방 코드 [제안]

- 6자리, 영문 대문자와 숫자 중 헷갈리는 `0 O 1 I`를 뺀 32글자. 약 10억 가지다.
- 방을 만들 때 서버가 무작위로 만들고 사용 중인 코드와 겹치면 다시 만든다.
- 입력은 대소문자 구분 없이 받는다. 코드 입력 실패를 1분에 10번 넘게 하면 잠시 막는다(`RATE_LIMIT`).
- 대기방은 10분 안에 상대가 안 들어오면 지운다.

## 4. 점수, 재화, 가챠, 계정

요청에 따라 계정, 재화, 가챠, 프롬프트 습관 분석을 이후 단계에서 앞당겨 구현했다. 자세한 설계는 10 문서에 있다. [확정]

### 4.1 판 안의 점수 [확정]
- 점수는 PASS한 문제 수이고 판이 끝나면 결과 화면과 계정 성적에 쓴다.

### 4.2 코인(재화) (구현됨)
- 사람과 한 판이 랭킹에 반영될 때만 받는다. 승리 +30, 무승부 +15, 패배 +10에 맞힌 문제 하나당 +1(최대 +10). [제안]
- 상대가 포기해서 이기면 +15(승리 보상의 절반), 포기하면 -10(참가비, 0 밑으로는 안 내려감). [제안]
- 하루에 재화를 받는 판은 10판까지다. 연습봇과 한 판, 튜토리얼, 무효 판은 재화가 없다. [제안]
- 가입하면 30코인을 준다. [제안]
- 쓰는 곳: 캐릭터 구매 120코인(골라서), 뽑기 50코인(안 가진 캐릭터 중 같은 확률). [제안]
- 모든 정산은 서버가 한다. 클라이언트가 보낸 값은 쓰지 않는다. [확정]
- 참가비는 포기한 쪽에게서만 걷는다. 판 시작 때 모두에게 걷는 방식은 쓰지 않는다. [확정]

### 4.3 랭킹 (구현됨)
- 요청에 따라 재화보다 먼저 구현했다. 기기 ID(브라우저 localStorage에 저장되는 값)를 기준으로 랭크 점수(RP)를 쌓는다. 로그인이 없어서 기기나 브라우저 저장소를 바꾸면 처음부터다. [확정]
- 점수: 승리 +25, 무승부 +5, 패배 -10(0 밑으로는 안 내려감). 상대 포기로 이기면 +12, 포기하면 -15. [제안]
- 등급: 브론즈 0, 실버 100, 골드 250, 플래티넘 500, 다이아 1000 이상. [제안]
- 순위: RP, 승수, 판 수 순. 상위 20명과 내 순위를 보여 준다. [제안]
- 반영하지 않는 판: 사람 둘이 아닌 판(연습봇, 튜토리얼), 같은 기기끼리 한 판, 시간 종료 판에서 두 사람 PASS 합계가 2 미만인 판, 같은 두 사람이 1시간에 5판을 넘긴 뒤의 판. 코드 방이라 친구끼리 점수를 모으는 것을 줄이기 위한 장치다. [제안]
- 서버가 계산하고 결과(`game:end`)에 `ranking`으로 실어 보낸다. 기기 ID는 밖으로 보내지 않는다. [확정]
- 저장은 `store.json`(환경변수 `DATA_FILE`로 위치 변경)에 한다. 서버를 다시 켜도 남는다. 이 파일은 git에 올리지 않는다. [제안]
- 한계: 기기 ID는 브라우저가 정하므로 조작할 수 있다. 진짜 계정이 생기기 전까지의 임시 방식이다. [제안]

### 4.4 가챠 (구현됨)
- 서버가 안 가진 캐릭터 중에서 같은 확률로 하나를 뽑는다. 이미 가진 캐릭터는 나오지 않고, 화면에 확률을 보여 준다. [제안]
- 처음에는 기본 4종(고양이, 비둘기, 강아지, 씹덕)을 모두 가지고, 나머지 캐릭터는 구매나 뽑기로 얻는다. [제안]
- 확률형 아이템 확률 공개 등 법적 요건은 확인하지 못했다. 재화는 경기로만 얻고 현금 결제가 없어서 해당하지 않을 가능성이 높지만 확인이 필요하다. [미정]

### 4.5 계정 (구현됨)
- 구글 로그인 또는 게스트. 구글 계정은 구글의 고유 번호(sub)와 이름만 저장하고 이메일과 비밀번호는 저장하지 않는다. [확정]
- 로그인 상태는 서버가 만든 무작위 토큰(브라우저 localStorage)으로 유지하고, 서버에는 해시만 저장한다. 계정당 토큰 5개, 90일 유효. [제안]
- 게스트 계정은 그 브라우저에만 남는다. 나중에 구글 계정을 연결하면 기록이 그대로 이어진다. [확정]
- 계정이 생기기 전 기기 ID로 쌓은 랭킹과 본 문제 기록은 처음 로그인할 때 계정으로 옮긴다. [제안]
- 계정 삭제와 기록 지우기를 제공한다. 삭제하면 랭킹, 재화, 캐릭터까지 모두 사라진다. [확정]
- 한계: 저장소가 JSON 파일(`store.json`)이라 서버 한 대, 디스크가 남는 환경에서만 안전하다. 여러 서버로 늘리려면 DB가 필요하다. [제안]

## 5. 부정행위 방지

| 위협 | 대책 | 라벨 |
|---|---|---|
| 클라이언트 금지어 검사 우회 | 서버가 같은 `checkPrompt`로 다시 검사 | 확정 |
| 프롬프트 길이 제한 조작 | 서버가 방 설정값으로 검사. 무제한은 2000자 상한 | 제안 |
| 클라이언트가 판정이나 점수를 조작 | 판정과 점수는 서버만 계산. 클라이언트가 보낸 값은 쓰지 않음 | 확정 |
| 다음 문제를 미리 엿봄 | 현재 문제만 전송 | 확정 |
| 상대 프롬프트 베끼기 | 상대 프롬프트는 판이 끝날 때까지 서버에서 안 내보냄 | 확정 |
| 시간 조작 | 모든 시간은 서버 시각 기준 | 확정 |
| Gemini 비용 폭주 | 플레이어당 동시 요청 1건, 전송 최소 간격 1초, 시간 초과 8초, 재시도 2회. 구현됨 | 확정 |
| 방 코드 무작위 대입 | 실패 횟수 제한 | 제안 |
| 메시지 폭주와 거대 메시지 | 8KB 상한, 소켓당 초당 40건 제한. 구현됨 | 확정 |
| 다른 사이트에서 서버 접속 | 웹소켓 `Origin` 검사(`ALLOWED_ORIGINS`로 예외). 구현됨 | 확정 |
| API 키 노출 | 키는 서버 환경변수에만 둔다. 클라이언트로 보내지 않고 저장소에도 올리지 않는다 | 확정 |
| 같은 `playerId`로 이중 접속 | 새 접속이 기존 접속을 대체. 단 같은 계정만 가능(남의 자리를 가로채지 못함) | 확정 |
| 일부러 끊어서 불리한 판을 피함 | 20초 후 부전패(보상 없음) | 제안 |
| 닉네임에 욕설 | 금칙어 목록으로 거절 | 확정 |
| 이모지 도배 | 0.8초 쿨다운(서버가 검사) | 제안 |

- 금칙어 목록의 내용(어떤 단어를 막을지)은 정하지 않았다. 첫 공개에서는 간단한 목록으로 시작한다. [미정]
